Description

Este proyecto tiene como propósito desarrollar un sistema integral de gestión para el control de acceso y operaciones dentro de un complejo empresarial, fundamentado en una base de datos relacional y el paradigma de programación orientada a objetos (POO). El sistema se estructura con un diseño relacional optimizado normalizado, diseñado en primer y tercer nivel global, y un modelo UML que representa la arquitectura del software y sus clases principales, garantizando una solución escalable, eficiente y trazable para cubrir las necesidades administrativas del complejo.
